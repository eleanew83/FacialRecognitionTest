How to review and save

Click a photo to compare the full crop with the original photograph. Select a problem category and add a suggested identity or note when useful. “OK” means no obvious issue on visual review; it does not certify the identity. Reference grids are also unverified.

With the local server running, decisions save into review_state.json in this review folder. A browser copy protects pending changes. Download a backup at the end of each session. Export flagged CSV for corrections and questions for Sylvain. This tool records decisions; it does not move, delete, crop or relabel images.
